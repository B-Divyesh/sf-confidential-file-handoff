Terms

Confidential File Handoff is a local utility that helps create password-protected ZIP files and clear recipient instructions. Use it only for files you are entitled to handle.

No security or compatibility guarantee

The tool cannot hide ZIP entry names, verify a recipient, secure a compromised device, prevent forwarding, remove malware, guarantee a channel’s safety, or satisfy a particular medical, legal, tax, privacy, or regulatory requirement. AES-256 ZIP support varies by extractor; test a non-sensitive handoff with the recipient’s intended app when compatibility matters. You choose the password and transfer channels and remain responsible for your use.

Pro costs US $9 as a one-time license unlock sold by Sociobot/Dodo, the merchant of record. A valid license unlocks the stated Pro feature on this app. Refunds are handled by the merchant and a refunded license may be revoked. Free core handoff features remain available without a purchase.

The app is provided as-is, without warranty. Always test a non-sensitive file with the intended recipient when the handoff matters.
