Your data

Privacy

Your browser creates the ZIP and handoff sheet on this device.

What stays on your device

The app does not upload selected files, access phrases, file names, or handoff sheets.

The handoff log stores a recipient, creation date, two routes, and optional sent and opened dates.

It does not store files, file names, or access phrases. ZIP entry names remain visible until you rename them.

Your choices

You can export, import, or delete the handoff log. Clearing this site’s browser storage removes handoff records and saved license results.

The demo uses a separate browser database. Reset demo clears that database. Start for real clears it before leaving.

Pro licenses

A license token is stored in this browser. When the app checks it, it sends the token to this site’s license gateway in a request body.

A verified result is reused for less than 24 hours.

The license gateway keeps only an irreversible browser identifier, a request count, and a one-minute expiry.

License responses are not cached by the gateway. Sociobot/Dodo handles payment. This app has no advertising trackers or third-party analytics.

Contact

Contact Sociobot support for privacy questions. Do not send files in support requests.
