Privacy

This app works on your device. It does not upload selected files, ZIP access phrases, file names, or file receipts.

What stays on your device

Your browser creates the ZIP locally. It may save a local receipt list in IndexedDB.

The list stores a recipient name, creation date, two routes, and optional sent and opened dates. It never stores files, file names, or access phrases.

ZIP entry names remain visible before an access phrase is entered. Rename file names before adding them if needed.

Your choices

You can export, import, or delete the local receipt list. Clearing this site’s browser storage removes it.

The demo uses separate browser storage. Reset demo clears its sample list. Start for real clears it before leaving demo mode.

Pro licenses

A license token stays in this browser. Sociobot checks it at most once a day while online.

The same-origin license gateway keeps a browser-identity digest for one minute. It also keeps a count for that minute. The digest limits license checks. It does not keep the license response.

Sociobot/Dodo is the merchant of record. This app has no advertising trackers or third-party analytics.

Contact

Contact the operator through Sociobot for privacy questions. Do not send files in support requests.
