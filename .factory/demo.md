# Demo sandbox

Open `/demo` or choose **Try it with sample data** on the first screen.

The demo seeds two fictional, redacted text files for Maya, an email ZIP route, a text-message password route, and a sample password. It uses the IndexedDB database `demo:confidential-file-handoff`, never the real `confidential-file-handoff` database. It does not read or write real license storage. **Reset demo** clears that demo database and reloads the sample. **Start for real** clears the demo checklist before leaving the demo URL, then uses the normal storage namespace.
